# Harness Wealth

> Harness (launched as Harness Wealth, today a wholly owned business of Multiplier, Inc.)
> runs an advisory platform for tax and wealth practices from New York City: a marketplace
> matching individuals with complex financial situations to vetted tax advisors, a client
> portal and workflow platform that tax firms run their engagements on, and Harness Wealth
> Advisers, LLC, an SEC-registered investment adviser. This file is an independent, third-party
> profile maintained by API Evangelist — it is not published by Harness.

## Machine-readable API surface

Harness publishes **no public developer program**. As probed on 2026-08-22 there is no
developer portal, API reference, OpenAPI/Swagger/GraphQL/AsyncAPI specification, SDK, CLI,
MCP server, A2A agent card or webhook documentation on any Harness host. `api.harness.co`,
`docs.harness.co` and `developer.harness.co` do not resolve. The legacy `api.harnesswealth.com`
record survives only as a dangling CNAME to Heroku with no address behind it. The product is
delivered entirely as an end-user web application.

Do not confuse this company with Harness Inc. (harness.io), the unrelated software delivery
platform, which does publish APIs.
